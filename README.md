# ❤️ Predictive Analytic Health Monitoring Using Machine Learning

### Major Project | PT-197

**IILM University, Greater Noida**

## 📌 Project Overview

This project aims to develop a Machine Learning-based Cardiovascular Disease Prediction System using an Artificial Neural Network (ANN).

The system analyzes health and lifestyle parameters to predict the presence or absence of cardiovascular disease based on a trained classification model.

A user-friendly web application is developed using Python and Streamlit.

## 🎯 Project Objectives

1. Analyze cardiovascular health risk factors.
2. Perform dataset cleaning and preprocessing.
3. Develop and train an ANN-based prediction model.
4. Evaluate the model using accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrix.
5. Develop an interactive web application for cardiovascular disease prediction.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Machine Learning:** Scikit-learn
- **Algorithm:** Artificial Neural Network (ANN / MLPClassifier)
- **Web Framework:** Streamlit
- **Data Analysis:** Pandas, NumPy
- **Development Environment:** VS Code
- **Version Control:** Git and GitHub

## 📊 Dataset

**Dataset:** Cardiovascular Disease Dataset

**Source:** Kaggle

**Records:** Approximately 70,000

**Features:**

- Age and Gender
- Height and Weight
- Blood Pressure
- Cholesterol and Glucose
- Smoking and Alcohol Consumption
- Physical Activity

**Target:** Cardiovascular Disease (0 = Absent, 1 = Present)

Dataset Link:
[https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset](https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset)

## 🚀 How to Run the Project

**Step 1: Install required libraries**

```bash
python -m pip install -r requirements.txt
```

**Step 2: Download the dataset**

Download `cardio_train.csv` from Kaggle and place it inside the `data` folder.

**Step 3: Train the model**

```bash
python train_model.py
```

**Step 4: Run the web application**

```bash
python -m streamlit run app.py
```

Open: [http://localhost:8501](http://localhost:8501)
